# Task 002.04: Generate Tailored Resume Markdown Before High-Score PDF Generation

## Epic

[Epic 002: Tailored Resume Markdown Support](002-tailored-resume-markdown.md)

## User Story

As a career-ops user, I want high-score jobs that trigger PDF generation to first create a tailored Markdown resume, then calculate a final score from that tailored resume, so the PDF and tracker both reflect the exact resume version used for the application.

## Requirements

- In auto-pipeline, pipeline, batch, and URL-evaluation flows, detect when a job score meets the configured PDF threshold.
- Before generating HTML/PDF output, invoke the same Markdown tailoring flow used by `career-ops resume-md`.
- Save the tailored Markdown resume at `output/cv-{candidate}-{company}.md`.
- Generate the PDF from the tailored Markdown resume content, not directly from base `cv.md`.
- Recalculate the score against the tailored Markdown resume and store it as `final-score`.
- Write both the Markdown path and `final-score` into tracker-addition TSV rows before merge.
- Preserve the direct `career-ops resume-md` behavior as Markdown-only; this task applies to flows that are already going to generate a PDF.
- If Markdown tailoring succeeds but PDF generation fails, keep `resume-md` and `final-score` in the tracker and mark PDF as pending/failed according to existing tracker conventions.

## Acceptance Criteria

- A high-score auto-pipeline run creates a tailored Markdown file before PDF generation.
- The generated PDF uses the tailored Markdown resume as its source.
- The merged tracker row has `resume-md`, `final-score`, and `PDF` populated in the correct columns.
- Low-score jobs below the PDF threshold do not generate a PDF, but direct `career-ops resume-md` can still create Markdown on demand.
- Regression coverage proves tracker TSV rows with `resume-md`, `final-score`, `PDF`, `Report`, `JD`, and `Notes` merge without column shifts.
