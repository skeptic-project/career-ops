# Task 002.03: Re-evaluate and Calculate final-score Based on Tailored Resume MD

## Epic

[Epic 002: Tailored Resume Markdown Support](002-tailored-resume-markdown.md)

## User Story

As a career-ops user, I want the system to calculate a new score against my tailored Markdown resume so I can verify that my tailoring improvements successfully address the JD's requirements.

## Requirements

- After the tailored Markdown resume is generated and saved, read its content.
- Perform the A-G evaluation blocks on the JD against this tailored Markdown resume instead of the base `cv.md` file.
- Save the resulting score as `final-score`.
- Record the path of the tailored Markdown resume and the calculated `final-score` in the tracker additions TSV file.
- Run `merge-tracker.mjs` to populate these values in `data/applications.md`.
- Keep the original job score intact in the `Score` column; `final-score` is an additional post-tailoring score, not a replacement.
- If final-score calculation fails, keep the tailored resume path, set `final-score` to a pending/empty sentinel, and record the failure in notes rather than blocking tracker integrity.

## Acceptance Criteria

- The tailored resume evaluation correctly computes a score.
- The `final-score` column in `data/applications.md` is populated with this tailored resume score (e.g. `4.7/5`).
- The `resume-md` column is populated with the correct path relative to the tracker file.
- `Score` continues to reflect the original base-CV evaluation while `final-score` reflects the tailored Markdown resume evaluation.
