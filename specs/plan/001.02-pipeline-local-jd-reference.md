# Task 001.02: Reference Local JD Files From Pipeline Entries

## Epic

[Epic 001: Persist Job Descriptions and Link Them Across Career-Ops](001-jd-persistence-pipeline-integrity.md)

## User Story

As a user processing pending jobs, I want `data/pipeline.md` to reference the local JD file so the pipeline evaluates stable local content instead of depending on a live external URL.

## Requirements

- Add pipeline entries in this format:

```markdown
- [ ] local:jds/<company-name>-<role>.md | Atlan | Engineering Manager
```

- Preserve company and role fields after the local path.
- Avoid duplicate pending entries for the same company, role, and JD path.
- Keep existing external URL entries compatible during migration.

## Acceptance Criteria

- New scan output can add local JD references to `data/pipeline.md`.
- Auto-pipeline can consume `local:jds/...` entries without re-fetching the external posting.
- Duplicate prevention handles the local JD path format.
