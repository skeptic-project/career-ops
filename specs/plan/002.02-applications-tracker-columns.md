# Task 002.02: Add Applications Tracker Columns for resume-md and final-score

## Epic

[Epic 002: Tailored Resume Markdown Support](002-tailored-resume-markdown.md)

## User Story

As a career-ops user, I want the applications tracker to store the paths of my tailored Markdown resumes and their re-evaluated scores, so I can track my tailored applications efficiently.

## Requirements

- Add `resume-md` column in `data/applications.md` before `PDF` column.
- Add `final-score` column in `data/applications.md` between `resume-md` and `PDF` columns.
- Update `tracker-parse.mjs` to map and parse these new columns.
- Update `merge-tracker.mjs` to automatically migrate the applications tracker to the new schema and support merging these fields.
- Update `verify-pipeline.mjs` to validate existence of `resume-md` files and formatting of `final-score` cells.
- Update regression tests in `tracker-columns-tests.mjs` to reflect the new layout.

## Acceptance Criteria

- `data/applications.md` has the new columns added.
- `merge-tracker.mjs` automatically updates existing layout files and correctly formats rows.
- `verify-pipeline.mjs` parses all fields and reports no errors on migrated layouts.
- Column regression tests pass successfully.
