# Task 002.01: Implement resume-md Argument for career-ops Command

## Epic

[Epic 002: Tailored Resume Markdown Support](002-tailored-resume-markdown.md)

## User Story

As a career-ops user, I want to run a command with the `resume-md` argument to generate a tailored version of my resume in Markdown format instead of HTML/PDF, so I can easily review and copy-paste it.

## Requirements

- Add `resume-md` to the mode routing table and argument specifications in `.agents/skills/career-ops/SKILL.md`.
- Create a new mode file `modes/resume-md.md` instructing the LLM agent to tailor `cv.md` for a given JD.
- Use `cv.md` as the exact base, preserving formatting, whitespace, heading levels, and structure.
- Personalization modifications must use targeted string replacements (`str_replace` operations) rather than rewriting the file from scratch.
- Save the resulting resume to `output/cv-{candidate}-{company}.md`.
- Read candidate name from `config/profile.yml`.
- Accept either a pasted JD, a JD URL, or an existing report/JD slug as input.
- Do not generate HTML or PDF when `career-ops resume-md` is invoked directly.

## Acceptance Criteria

- Running `career-ops resume-md` triggers the resume-md mode.
- The tailored resume is saved as a Markdown file in the `output/` directory.
- The structure and formatting matches `cv.md` exactly, with only targeted keyword improvements and reordering.
- The direct `resume-md` mode exits with a Markdown artifact only; PDF generation remains a separate mode unless invoked by auto-pipeline.
