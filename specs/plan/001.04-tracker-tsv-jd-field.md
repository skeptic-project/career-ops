# Task 001.04: Carry JD Path Through Tracker TSV Generation

## Epic

[Epic 001: Persist Job Descriptions and Link Them Across Career-Ops](001-jd-persistence-pipeline-integrity.md)

## User Story

As the pipeline records evaluated jobs, I want tracker-addition TSV rows to include the local JD path so `merge-tracker.mjs` can write it into `data/applications.md`.

## Requirements

- Extend tracker-addition TSV generation to include JD path.
- Preserve compatibility with current TSV rows:
  - Existing 9-column format should still merge.
  - New format should include a JD field after report and before notes, or another documented position.
- Update documentation in `AGENTS.md` or the relevant mode files once implementation happens.
- Ensure generated JD paths are root-relative before merge, similar to report links.

## Acceptance Criteria

- New tracker-addition TSV rows carry a JD path.
- Old TSV additions still merge without a JD value.
- Pending and merged TSV directories remain valid after the schema change.
